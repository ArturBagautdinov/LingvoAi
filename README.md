# 📱 LingvoAI

**LingvoAI** — iOS-приложение для изучения языка с использованием AI.

Объединяет чат с ассистентом для языковой практики и квизы для проверки знаний в одном мобильном приложении.

Pet-project, созданный для практики архитектуры iOS-приложений, работы с Firebase и интеграции AI.

---

## 🚀 Функциональность

- 🔐 Авторизация и регистрация (Firebase Auth)
- 🤖 AI-чат для языковой практики
- 🧠 Квизы с генерацией вопросов через AI
- 👤 Профиль пользователя (Firestore)
- 📱 Многоэкранная навигация через Tab Bar

---

## 🛠 Стек технологий

**iOS:** Swift, SwiftUI  
**State:** ObservableObject, `@State`, `@Published`  
**Backend:** Firebase Auth, Firebase Firestore  
**AI:** OpenAI API  
**Асинхронность:** async/await, Task  
**Данные:** JSON, Codable  
**Инструменты:** Xcode, Git

---

## 🧩 Структура проекта

- **Auth** — логин / регистрация
- **ChatBot** — AI-чат
- **Quiz** — модуль тестов
- **Profile** — данные пользователя
- **Models** — модели данных
- **UI Components** — переиспользуемые элементы интерфейса

---

## 🎯 Цель проекта

Практика:

- разработки многоэкранного iOS-приложения
- работы со SwiftUI
- интеграции Firebase и OpenAI
- построения пользовательских сценариев и логики приложения

---

## ⚙️ Запуск

1. Открыть проект в Xcode
2. Добавить `GoogleService-Info.plist` (Firebase)
3. Указать OpenAI API key
4. Запустить на симуляторе или устройстве

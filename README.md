📱 LingvoAI
LingvoAI — iOS-приложение для изучения языка с использованием AI.
Объединяет чат с ассистентом для языковой практики и квизы для проверки знаний в одном мобильном приложении.
Pet-project, созданный для практики архитектуры iOS-приложений, работы с Firebase и интеграции AI.<br><br>
🚀 Функциональность<br>
🔐 Авторизация и регистрация (Firebase Auth)<br>
🤖 AI-чат для языковой практики<br>
🧠 Квизы с генерацией вопросов через AI<br>
👤 Профиль пользователя (Firestore)<br>
📱 Многоэкранная навигация через Tab Bar<br><br>
🛠 Стек технологий<br>
iOS: Swift, SwiftUI<br>
State: ObservableObject, @State, @Published<br>
Backend: Firebase Auth, Firebase Firestore<br>
AI: OpenAI API<br>
Асинхронность: async/await, Task<br>
Данные: JSON, Codable<br>
Инструменты: Xcode, Git<br><br>
🧩 Структура проекта<br>
Auth — логин/регистрация<br>
ChatBot — AI-чат<br>
Quiz — модуль тестов<br>
Profile — данные пользователя<br>
Models — модели данных<br>
UI Components — переиспользуемые элементы интерфейса<br><br>
🎯 Цель проекта<br>
Практика:<br>
разработки многоэкранного iOS-приложения<br>
работы со SwiftUI<br>
интеграции Firebase и OpenAI<br>
построения пользовательских сценариев и логики приложения<br><br>
⚙️ Запуск<br>
Открыть проект в Xcode<br>
Добавить GoogleService-Info.plist (Firebase)<br>
Указать OpenAI API key<br>
Запустить на симуляторе или устройстве<br>
